データの取得方法

VocaDBの楽曲データを検索し、曲の詳細を開くとニコニコ（スナップショット検索API）とiTunes（JSONP）で候補を自動検索します。誤登録を避けるため、候補は自動で確定せず、確認後に採用します。YouTubeは登録済みリンクを表示し、必要に応じて無料枠のYouTube Data APIキーで投稿チャンネルIDを照合します。キーなしでもチャンネルURLの手動照合ができます。

ニコニコAPIはサイトのブラウザ通信が制限される場合があります。その場合は外部検索をご利用ください。iTunesの配信日は実際の初回配信日とは異なる場合があります。

YouTube投稿者チャンネルの自動照合（任意）

APIキーなしでもVocaDBの公式チャンネル候補と投稿者URLの手動照合が利用できます。YouTube Data API v3のキーを設定すると、動画のchannelIdと公式チャンネルを照合できます。キーはブラウザのセッションにのみ保存し、バックアップやGitHubには含めません。公開ブラウザのキーは完全な秘密にはできません。Google Cloud側でYouTube Data API v3のみに制限し、GitHub PagesのHTTPリファラー制限を設定してください。

BPM・動画URL・配信日をバックアップ

BPM・公式チャンネル・投稿者URLの手動登録はこの端末・ブラウザ内に保存されます。別の端末へ移すにはJSONのエクスポート／インポートを使います。自分で追加した不足曲もバックアップされます。

データ利用について

アーティスト名の完全一致候補は自動で選択し、最大500曲を順次読み込みます。外部で確認した補完曲は参考元を明示します。VocaDBの「Original PV」は公式・権利者許諾の動画を示し、投稿アカウントが本人かまでは保証しません。検索時・詳細表示時に外部サービスと通信します。サイト独自のサーバーやユーザー登録はありません。CSVには現在の表示結果のみが含まれます。
