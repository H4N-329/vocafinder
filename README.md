# VocaFinder v5.0 — 公式YouTube投稿チャンネル照合

**GitHub Pagesで無料公開できる静的サイト**です。v4の曲名・アーティスト検索、VocaDB、ニコニコ・iTunes補完、BPM、投稿日順、カバー/Remixフィルター、手動編集、CSV、JSONバックアップを残したまま、投稿者の確認機能を追加しました。

## GitHub Pagesでv4から更新する

1. ZIPを解凍します。
2. GitHubのリポジトリを開きます。**Add file → Upload files** をクリックします。
3. **`index.html`、`styles.css`、`js`フォルダ全体、`.nojekyll`** をリポジトリの直下にアップロードします。`vocafinder-v5-site`という親フォルダは置かないでください。`README.md`は任意です。
4. 同名ファイルを更新して **Commit changes**。**Settings → Pages → Deploy from a branch → main → /(root)** を確認してください。
5. 更新が反映されないときはMacで **Command + Shift + R** で強制再読み込みを試してください。

`js/official.js`、`js/youtube.js`、`js/channel-data.js` が新規ファイルです。`js`内の**全ファイル**をアップロードしてください。

## 公式チャンネル確認の使い方（APIキーなし・月額0円）

1. 検索対象を「アーティスト」にし、`r-906` などで検索します。
2. アーティストを選択すると、VocaDBの `Official` 区分のアーティスト外部リンクからYouTubeチャンネルURLを抽出します。
3. **公式チャンネルを管理** を開き、登録されているリンクを確認します。なければご本人の公式サイト・SNSなどで確認し、YouTubeのチャンネルURLを1行ずつ登録します。
4. 楽曲カードから **詳細・編集 → YouTube投稿者チャンネル照合** を開きます。YouTube動画の投稿者チャンネルを実際に確認して、そのURLを入力し **手動照合** を押してください。
5. 両方のチャンネルURLが一致すると **「登録チャンネル一致（要確認）」** と表示します。`/@ハンドル` であっても、同じハンドル文字列であれば比較できます。ユーザーの入力を根拠とした照合なので、**自動API検証とは区別**します。
6. **本人チャンネル一致のみ** のチェックで確認済み候補だけを絞れます。CSVにも判定欄を出力できます。

重要：YouTubeはAPIキー不要で動画ID→投稿者のチャンネルIDを確実に取得できる公式の匿名APIを提供していません。キーなしのモードでは、本人投稿を全曲自動確定することはできず、投稿者URLの手動入力が必要です。**曲名、投稿動画のタイトル、VocaDBの「Original PV」だけでは本人投稿と判定しません。**

## YouTube Data API v3による自動照合（任意・Googleの無料割り当て枠）

GitHub Pagesのまま、**YouTube Data API v3のAPIキー**を使って動画の正確な投稿者チャンネルIDを取得できます。無料枠で収まる通常の小規模利用を想定しており、無制限・無条件の無料を保証するものではありません。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成します。
2. **APIとサービス → ライブラリ → YouTube Data API v3** を有効化します。
3. **APIとサービス → 認証情報** からAPIキーを作り、**APIの制限：YouTube Data API v3だけ** に設定します。
4. **アプリケーションの制限：ウェブサイト（HTTPリファラー）** を選び、**`https://あなたのユーザー名.github.io/*`** を許可します。公開URLの構成によってはリファラー制限のパターンを調整してください。
5. VocaFinderの **設定・バックアップ** でAPIキーを入力し、**キーを適用** を押します。**キーをHTML・JS・GitHubリポジトリへ直接書き込まないでください**。
6. アーティストを選択し、**YouTube投稿者を照合** を押します。すでにAPIキーを設定してアーティストを検索した場合は、楽曲取得後に自動照合も試みます。
7. アーティストのハンドル→チャンネルIDを`channels.list(forHandle)`、動画ID→投稿者チャンネルIDを`videos.list(part=snippet)`で取得します。最大50動画を1回の`videos.list`でまとめて照合し、成功結果をセッション内で最大24時間キャッシュします。

### 判定の区別

- **本人チャンネル一致（VocaDB公式）**：VocaDBの`Official`リンクで示されたYouTubeチャンネルIDと、YouTube Data APIから取得したその動画の`snippet.channelId`が一致。
- **登録チャンネル一致（要確認）**：手動登録した公式チャンネルや、手動登録の動画投稿者URLとの照合が一致。出典は利用者自身の確認で、自動照合とは分けます。
- **別チャンネル投稿（登録済み動画）**：現在登録されている該当動画の投稿者チャンネルが既知の公式チャンネルと一致しない。ただし本人の別チャンネルや代理投稿もあるため、非公式・無許諾とは限りません。
- **投稿者未照合**：動画の投稿者情報をまだ取得・登録していない。**未確認を「別チャンネル」と誤判定しません。**

同じ曲のYouTube動画が複数ある場合はすべての登録動画をチェックし、公式チャンネルに一致する動画が**1つ以上**あれば一致扱いします。対象は**VocaDB登録動画やユーザー手動追加済み動画**であり、YouTubeにある全動画を網羅するものではありません。

**セキュリティ注意**：GitHub Pagesは静的サイトです。ブラウザから利用するAPIキーはネットワーク通信などで閲覧可能なため**秘密鍵として保護できません**。Google Cloudで**YouTube Data API v3へのAPI制限とHTTPリファラー制限を必ず設定**し、割り当て上限を監視してください。本サイトのキーはブラウザの**sessionStorageにのみ保存**し、CSVやJSONバックアップには含めません。さらに高い保護が必要ならGitHub Actions等でサーバー側照合に移行してください。

## データと制約

- VocaDBはCORS対応。ニコニコAPIにはCORS等の制限があり、iTunesの`releaseDate`は初回配信日と一致するとは限りません。
- 公式チャンネル一覧はVocaDB登録内容に依存し、登録漏れや誤分類があり得ます。複数の公式・サブチャンネルを使う方は個別登録してください。
- アーティスト作品の自動取得はVocaDBの検索結果**最大500曲**です。未登録作品は従来どおり手動追加や補完データに依存します。YouTubeで公式動画を見つけても、曲として自動追加することはしません。
- 本人確認・権利保有を法的に証明するものではありません。動画が公式に投稿されていても、必ずしも著作権を持つアカウントとは限りません。
- v4の編集データは維持されます。v5のJSONバックアップは公式チャンネル登録と動画投稿者の手動照合も含み、v4バックアップの取り込みも可能です。APIキー・APIから得た一時キャッシュはバックアップに含めません。
- モックデータでのブラウザ操作テストと単体テストは通過しています。**実際のVocaDB・YouTubeの公開APIへの通信や、実サイトでの判定はこの環境では未検証**です。

## 開発者向け

```
index.html
styles.css
.nojekyll
js/
  api.js, app.js, artist.js, manual.js, storage.js, supplement.js, utils.js
  official.js       チャンネルID・ハンドル正規化、複数PV判定、並び替え
  youtube.js        任意のYouTube Data API v3接続、セッション内キャッシュ
  channel-data.js   公式チャンネル/投稿者の手動登録と検証
```

`npm test` で10件の単体テストを実行できます。配布ZIP内にはテストスクリプトを含めません。
